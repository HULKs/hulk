# Charging box

The charging-box design and bill of materials are documented in
`docs/tooling/charging_box/overview.md` and
`docs/tooling/charging_box/building_your_own.md`.

See the [repository overview](https://github.com/HULKs/hulk/blob/main/docs/tooling/charging_box/overview.md)
for charging/network capacity and the construction guide for part specifications.
CAD source/exports are under `tools/charging-box/cad`; PCB source and fabrication
files are under `tools/charging-box/pcb`. Supplier availability is not tracked by
the repository.
