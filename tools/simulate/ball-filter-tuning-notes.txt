Ball filter realism and optimization work log
===========================================

Objective
Automatically improve the production ball filter from ordinary ROS-Z MCAP
recordings, with the same replay path usable for real robot recordings.
Current invariant: optimization uses exactly one reference ball; multiple balls
are an explicit unscored live-preview stress test only (user clarification).
Keep production kinematics and absolute simulator torso reference; simulation
does not depend on visual localization. User explicitly authorized a soft live
field-boundary confidence prior using the available field pose (2026-10-03).
Maintain git checkpoints as work progresses.

Realism backlog, after contested-ball baseline is measured
- Camera/exposure and detector delivery latency/jitter, retaining acquisition time.
- Motion blur and partial occlusion rather than binary center-ray occlusion.
- Correlated encoder zero offsets, camera extrinsic/intrinsic calibration errors,
  IMU bias and ground estimate errors; retain pristine physical camera/truth.
- Surface/friction variation and articulated opponent contacts. Current opponent
  cylinders are kinematic and effectively infinite mass; controlled robot must
  retain clearance and real fall detection.
- Measure field-prior pose coverage on real recordings. Production ground_to_field
  follows timestamped visual-odometry/localization outputs, unlike the simulator's
  frequent absolute reference. If the 20ms gate yields poor coverage, consider
  explicit odometry propagation to filter time rather than reusing stale Ground
  transforms. Keep the exact selected pose diagnostic for deterministic replay.
- Timestamp-aware behavior handoff using odometry to bring historical Ground
  coordinates forward; do not depend on visual localization or extrapolate using
  last_seen (that is detection time, not filter state time).
- Capture repeatable held-out contested cases and compare near-foot errors,
  unseen-kick reacquisition, false tracks and availability together.
- New wall-stress capture train42 spends much of its labelled time outside the
  lines (14,158 output-aligned outside truth samples with active prior). Weighted
  scoring accounts for rarity, but future scenario distribution should include
  more sustained in-field contests and fewer long wall-side rolls. Preserve real
  physics; any re-entry should be an explicit kick/throw-in scenario, not teleport
  or an invisible continuous attraction to the field center.
