# Experimental K1 simulator

This checkout does not contain a `simulate` crate or root `simulator` launcher.
MuJoCo-based K1 simulator development lives on
[Alex's `motion-inference-simulator` branch](https://github.com/alexschmander/hulk/tree/motion-inference-simulator).
Use that branch's README and command help with its matching source, dependencies,
and model assets.

See the [simulator guide](../../docs/tooling/behavior_simulator.md) for checkout
instructions. For behavior scenarios available in this workspace, use
[`bevyhavior_simulator`](../../docs/tooling/behavior_tree_simulator_design.md).
