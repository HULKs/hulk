# Historical Documentation

These pages preserve documentation of the older NAO cycler-based stack and its tooling.
They are useful for understanding previous algorithms and architecture; their runtime descriptions and commands refer to that older stack.

- [Robotics Overview](robotics.md): the Control, Vision, Audio, SPLNetwork, and Hydra cyclers.
- [Vision](vision.md): segmented-image processing, line detection, ball detection, and debug views.
- [Audio](audio.md): NAO microphones and whistle detection.
- [Bevyhavior Simulator](behavior_simulator.md): the original simulator usage and scenario layout.
- [Pepsi](pepsi.md): the older Webots and NAO build and deployment workflows.
- [Profiling](profiling.md): the old NAO performance-analysis recipe.
- [Motion](motion/overview.md), [walking](motion/walking.md), and [step planning](motion/step_planning.md): the previous motion-selection and walking-engine architecture.
- [Setup](setup/overview.md): the original development environment, team configuration, NAO image/SDK, flashing, and upload guides.
- [Operating System](operating_system/overview.md): NAO filesystem, Linux, partitioning, networking, and HULA documentation.

For the current stack, start with the [robotics overview](../robotics/overview.md) and [tooling overview](../tooling/overview.md).
